Affiliate-Fabrik

So baust du mit Claude Code deutschsprachige Affiliate-Nischenseiten: von der Themenprüfung bis zum Deployment.

1. Einmal einrichten (pro MacBook)

git clone https://github.com/SOE07/site_builder.git
cd site_builder
nvm install && nvm use

nvm liest .nvmrc (Node 26 LTS; Astro braucht mindestens 22.23.4). Danach claude im Repo-Ordner starten und die Projekt-Einstellungen bestätigen. Skills, Agents und Hooks liegen im Repo unter .claude/, auf dem Rechner ist nichts weiter nötig.

2. Neue Seite bauen

In Claude Code, in dieser Reihenfolge. Jede Aufgabe läuft auf einem eigenen Branch und endet mit einem Pull Request gegen main.

BefehlErgebnis
/nische-pruefen <Thema>Bericht in recherche/ mit Punktzahl und Empfehlung (Go, Bedingt, No-Go)
/seite-anlegen <name> "<Anzeigename>"seiten/<name>/ mit eigenem Theme und Pflichtseiten
/keyword-plan <name>Keyword- und Artikelplan, kaufnahe Suchanfragen zuerst
/produkte-recherchieren <name> <Produkte>Produktdaten, jede Angabe mit Quell-URL und Prüfdatum
/artikel-schreiben <name> <Artikel>Ratgeber aus den vorhandenen Daten
/qualitaet-pruefen <name>Skripte plus Faktenprüfer, Compliance und SEO-Prüfer, Bericht in planung/
/preise-aktualisieren <name>Preise und tote Links prüfen, Änderungen als Pull Request

Die Regeln stehen in CLAUDE.md: keine Behauptung eigener Tests oder Erfahrung, keine Sterne oder Noten, jede Produktangabe mit Quelle und Prüfdatum, Werbekennzeichnung an jedem Affiliate-Link. Eigene Erfahrung darf nur auf die Seite, wenn du sie in seiten/<name>/erfahrung/<produkt>.md einträgst.

3. Seite lokal starten

cd seiten/<name>
npm install
npm run dev

Die Seite läuft dann unter http://localhost:4321, die Redaktion unter /keystatic (lokaler Modus). Vor jedem Pull Request npm run check ausführen: Es prüft Daten, verbotene Phrasen, Build, Werbekennzeichnung und interne Links. npm run check:release ist strenger und schlägt bei offenen Platzhaltern und fehlenden Prüfdaten fehl.

4. Auf Netlify oder Vercel deployen

Jede Seite ist ein eigenes Projekt. Neues Projekt aus diesem GitHub-Repo anlegen:

EinstellungWert
Base Directory / Root Directoryseiten/<name>
Build Commandnpm run build
Outputdist
Node-Version26 (mindestens 22.23.4)

Ohne Online-Redaktion braucht es keine Umgebungsvariablen. Für Keystatic im GitHub-Modus zusätzlich DEPLOY_TARGET (netlify oder vercel), KEYSTATIC_STORAGE=github und die Zugangsdaten einer eigenen GitHub-App je Seite setzen. Die Namen stehen in .env.example, Werte gehören nie ins Repo.

Vor dem Livegang: npm run check:release muss grün sein, Impressum und Datenschutz müssen ausgefüllt und die Partnerlinks eingetragen sein.
