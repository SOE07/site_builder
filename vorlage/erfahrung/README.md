# Eigene Erfahrung

Nur hier darf eigene Erfahrung stehen, je Produkt eine Datei `erfahrung/<produkt-slug>.md`
(Dateiname = Slug in `src/content/produkte/`). Der Inhalt erscheint unter dem Produkt im Ratgeber
als „Eigene Erfahrung“. Schreibe nur auf, was wirklich selbst erlebt wurde, mit Datum, z. B.:

    Gespielt von Mai bis Juli 2026, etwa zehnmal. Der Griff war mir zu dünn.

Ohne Datei erscheint kein Erfahrungsblock. Leere oder erfundene Dateien nicht anlegen.
